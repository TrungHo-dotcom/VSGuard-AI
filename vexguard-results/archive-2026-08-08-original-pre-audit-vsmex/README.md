# Archived: original VsMex results (2026-08-08, pre-audit)

`results-vsmex.csv` / `results-vsmex.jsonl` in this folder are the VsMex
corpus results from the **original evaluation run (2026-08-08)**, produced
by the engine **before** the 2026-08-11/12 audit fixes documented in
`docs/CHANGES-v3.md` §12–13.

Moved out of `vexguard-results/` on 2026-08-13 so they are not silently
mixed into fresh analysis of the re-run DataDog corpus (which used the
patched engine). The vsmex-dataset (3,790 samples) itself is not available
on this machine — no public source was found (see chat history / project
notes) — so these results cannot be regenerated with the current engine.
Treat any number derived from these two files as reflecting the
**pre-audit** engine, not the current one.
